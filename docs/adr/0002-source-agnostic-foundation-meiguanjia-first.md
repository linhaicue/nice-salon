# Source-Agnostic Foundation, Meiguanjia First

The Enterprise Evidence Foundation must not assume that every enterprise fact comes from Meiguanjia; Meiguanjia is the first and currently most important structured source, and future sources can be added as evidence requires. We reject both a Meiguanjia-specific foundation and connecting every possible source up front: Slice 1 implements only the Meiguanjia page-level reader, without a generic plugin registry or dynamic adapter framework. Long-term Meiguanjia coverage is incremental and limited to business-meaningful data readable under the authorized account. See [Foundation #10](https://github.com/linhaicue/nice-salon/issues/10).
