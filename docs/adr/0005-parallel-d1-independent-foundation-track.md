# Run a D1-Independent Foundation Track in Parallel

Wayfinder D1 remains open while a parallel Foundation Track may build only durable capabilities that do not depend on which business loop D1 selects. We reject both blocking all foundation work until D1 closes and using the parallel track to prebuild scenario-specific intelligence: the current slice is limited to reusable evidence acquisition, provenance, classification, minimal canonical relationships, freshness, and current fact views. See [Master Map #1](https://github.com/linhaicue/nice-salon/issues/1) and [Foundation #10](https://github.com/linhaicue/nice-salon/issues/10).
