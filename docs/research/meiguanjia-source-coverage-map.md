This map identifies business-meaningful Meiguanjia domains and separates menu existence from actual shop use, data semantics, and dependable read access. It is not a schema, API catalogue, or claim that all listed modules are currently used.

## Evidence key

- `LIVE_PAGE_OBSERVED`: directly read from a currently authenticated Meiguanjia page during the documented Slice 1 work.
- `HISTORICAL_MENU_ONLY`: present in the earlier read-only menu exploration summary; no reproducible page payload or current live re-check is stored in this checkout.
- `USER_CONFIRMED`: explicitly confirmed by the business owner.
- `NOT_TESTED`: not established by current evidence.
- `UNKNOWN`: the question has not been answered with adequate evidence.

The map uses `E / U / T / G / I / F / R / V` for **Exists / Used / Fact Type / Granularity / Identity / Freshness / Readability / Foundation Value**. Values like “likely” or “candidate” are hypotheses from menu labels and must be checked on the page before they become source contracts.

## What current evidence supports

1. **Water-bill mechanism:** the Slice 1 evidence supports a narrow, read-only page capture and persistence path for one selected consumption record. It does not prove complete transaction-domain coverage or an automated source adapter.
2. **Existing analysis is a reuse opportunity, not a contract yet:** traffic, churn risk, capacity, service quality, project analysis, employee traffic, and balances are historical menu discoveries. Their formulas, dimensions, refresh, and actual use remain unknown. Treat them as `SOURCE_DERIVED_METRIC` candidates only after live definition review.
3. **Workflow reality is independent of menus:** appointments and SMS were confirmed as unused in the current daily workflow. For every other module, usage remains `UNKNOWN` until a person confirms it or a real operating flow is observed.
4. **Identity is still a coverage gap:** bill records expose source references, but the customer reference has not yet been proven to match the customer master key. Employee and service master links also remain unverified.
